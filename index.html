How to use in Word / Government files

  1. Verify Hindi text above is correct (matras, punctuation, full stops)
  2. Click Copy Kruti Dev — copies encoded text to clipboard
  3. Paste in MS Word / LibreOffice
  4. Select all pasted text → set font to Kruti Dev 010 (or Kruti Dev 011 per office standard)
  5. English headings: type separately in Times New Roman — Kruti Dev renders English as Hindi glyphs

Runs entirely on your device — no server, no tracking. Proofread official documents after converting.
