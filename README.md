# KrutiDev Converter Offline

> ⚡ A fast, lightweight and privacy-friendly KrutiDev Hindi text converter that works completely offline.

KrutiDev Converter Offline is a browser-based Hindi font conversion tool designed to convert Hindi text between **Unicode** and **KrutiDev** formats without requiring an internet connection.

The conversion is performed directly inside the user's browser, making the application fast, private and suitable for offline use.

---

## ✨ Features

- 🔄 Unicode ↔ KrutiDev conversion
- ⚡ Instant text conversion
- 📴 Works completely offline
- 🔒 No text is uploaded to any server
- 🚀 Lightweight and fast
- 🌐 Runs directly in a web browser
- 📱 Responsive interface
- 📦 Progressive Web App (PWA) support
- 💾 Service Worker based offline caching
- 📋 Easy copy/paste workflow
- 🇮🇳 Designed for Hindi users and legacy KrutiDev workflows

---

## 🧠 Why KrutiDev Converter?

KrutiDev is a widely used legacy Hindi font encoding, especially in older documents, government offices, typing workflows and Hindi data-entry systems.

Modern applications generally use **Unicode Devanagari**, while older systems may still contain KrutiDev encoded text.

This project provides a simple way to convert between these formats without depending on an online API.

### Example

**Unicode:**
नमस्ते भारत

**KrutiDev**
ueLrs Hkkjr
